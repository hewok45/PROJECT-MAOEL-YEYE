# 📸 Pothooo Booth Maoel

> 🎨 Frame foto & template photobooth yang lucu, simpel, dan estetik.

**Pothooo Booth Maoel** adalah website yang menyediakan berbagai pilihan
frame dan template untuk membuat tampilan foto menjadi lebih menarik.
Website ini memiliki desain dengan warna pastel dan tampilan yang sederhana
sehingga nyaman digunakan.

---

## ✨ Fitur Website

- 📸 Pilihan berbagai frame foto
- 🎨 Template dengan berbagai tema
- 📱 Tampilan yang responsif
- 🌈 Desain warna pastel yang menarik
- 🖼️ Pilihan ukuran Story Instagram, 4R, dan 2R
- 💜 Tampilan sederhana dan mudah digunakan
- ✨ Animasi dan efek hover pada beberapa bagian website

---

## 🖼️ Pilihan Frame

Website ini menyediakan beberapa frame dari **Maoel Series**, yaitu:

1. 💜 **Lilac Dream Strip**
   - Frame ungu lembut dengan desain bintang.

2. 🌿 **Mint Polaroid Grid**
   - Frame bergaya polaroid dengan warna mint.

3. 🍑 **Peach Scallop Booth**
   - Frame bernuansa peach dengan gaya vintage.

4. 💙 **Sky Confetti Frame**
   - Frame biru langit dengan dekorasi confetti.

5. 💗 **Blush Heart Frame**
   - Frame pink dengan dekorasi hati.

6. 🌼 **Sunny Daisy Strip**
   - Frame kuning pastel dengan motif bunga daisy.

---

## 📐 Pilihan Ukuran

Website memiliki beberapa kategori ukuran:

- 📱 Story Instagram
- 🖼️ 4R
- 🆕 2R

Pengguna dapat memilih kategori sesuai kebutuhan foto.
